# Trabajo Práctico Integrado
## Gestión de datos de Países en Python

# Integrante
- Silva Lourdes

## Descripción 
Este proyecto consiste en una aplicación desarrollada en Python que permite gestionar información de países mediante 
un sistema en consola.

El programa permite:
- Agregar países
- Actualizar datos
- Buscar países
- Filtrar información
- Ordenar registros
- Mostrar estadísticas

## Tecnologías utilizadas 
- Python 3
- CSV
- GitHub

## Funcionalidades 
- Gestión de países
- Búsquedas
- Filtros
- Ordenamientos
- Estadísticas


## Cómo ejecutar el programa
```bash
python main.py
```
